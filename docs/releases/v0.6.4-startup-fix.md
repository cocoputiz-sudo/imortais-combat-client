# IMORTAIS Combat Client v0.6.4 | Correção de abertura do piloto core

## CORREÇÃO URGENTE: CLIENTE TRAVADO EM "RASTREANDO (100%)"

- Corrige o cliente v0.6.3 que podia ficar com a janela de carregamento **Rastreando (100%)** aberta depois do aviso inicial do Death Review.
- A janela de carregamento agora conclui e fecha antes do aviso do piloto core. O aviso é agendado por `App.OnStartup` **depois de `toolLoadingWindow.Close()`**, usando `DispatcherPriority.ApplicationIdle`.
- A janela principal recebe foco e é definida como proprietária do aviso. Se o cliente iniciar **oculto na bandeja**, nenhum diálogo é aberto nesse estado. O aviso fica pendente e aparecerá quando o jogador restaurar a janela.
- A resposta ao aviso é salva de forma **assíncrona**, sem bloquear a interface WPF enquanto o arquivo de preferências é gravado.
- Um problema ao apresentar o aviso não deve impedir a abertura do aplicativo.
- Preserva o pareamento existente com o War Room, o envio normal de telemetria, o Guild Might/Challenge, os highlights, as configurações e os controles do Death Review.

## DEATH REVIEW PRÉ-HABILITADO: piloto core

- O piloto continua **pré-habilitado**, mas o registro só começa depois que o jogador reconhece o aviso. No modo de inicialização na bandeja, o aviso continua pendente, a coleta permanece inativa, e o jogador poderá confirmar ao restaurar a janela. O aviso **não é marcado como lido automaticamente**.
- O aviso informa que os **45 segundos anteriores à própria morte** poderão ser registrados localmente com danos recebidos, IDs/nomes observados, índices de habilidades, equipamento e formas dos eventos Photon.
- O jogador pode escolher **manter ligado** ou **desligar**. A escolha é persistida, inclusive após outras atualizações.
- Para quem já concluiu o aviso da v0.6.3, a v0.6.4 **não mostra o aviso novamente**.
- Relatórios são armazenados somente no computador, até **30 arquivos JSON**, acessíveis por **ABRIR DEATH REVIEWS**.
- **NÃO há envio automático** ao War Room, à liderança ou a um modelo de IA.
- Gravação de vídeo é independente e não é habilitada por esta atualização.
- A interpretação exata de Q/W/E/poção e cooldowns depende de homologação de dados de uma morte real.

## Como conferir

1. Atualize a partir da v0.6.3 mantendo o pareamento.
2. Abra o Combat Client: a tela **Rastreando (100%)** deve desaparecer quando a janela principal estiver pronta.
3. Se o aviso estiver pendente, selecione **Sim** para manter o Death Review ligado ou **Não** para desligá-lo.
4. Confirme a opção no painel IMORTAIS e reinicie o programa. Ele deve abrir normalmente, sem repetir o aviso.
5. Para testar uma morte, deixe o Combat Client capturando o jogo; depois consulte **ABRIR DEATH REVIEWS**.

A atualização v0.6.4 é uma correção da inicialização; não adiciona coleta remota e não altera os dados de combate analisados.
